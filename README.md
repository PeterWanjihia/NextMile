# NextMile Rentals

NextMile Rentals is a mobile-first vehicle-rental platform for gig and delivery drivers.

## V1 objective

V1 will provide:

- A professional seven-page public website
- A guided driver application flow
- Application confirmation
- Responsive mobile-first UX
- A foundation for the later applicant and fleet-management system

## Initial pages

1. Homepage
2. Fleet
3. Pricing
4. Requirements and FAQ
5. Application
6. Application confirmation
7. Contact

## Technology

- Nuxt 4
- Vue 3
- TypeScript
- Tailwind CSS
- pnpm

## Project structure

- `docs/` — scope, brand system and approved design references
- `frontend/` — Nuxt application
